# 📦 Logistics ERP - New Booking Entry Form

---

## 🛠 Technologies Used

- React (TypeScript)
- Tailwind CSS
- React Hook Form 

---

## 📦 Dependency Installation

First, install all required dependencies:
npm install

Run Project Locally:
npm run dev
